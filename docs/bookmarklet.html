スマホから保存する

スマホの Chrome や Safari には拡張機能が無いため、代わりに ブックマークレットを使います。OALD の意味ページで実行すると、 保存する語義を選ぶ画面が出ます。

先に 単語帳 をホーム画面に追加し、Drive 同期を 済ませておくと、保存した単語がそのまま他の端末にも届きます。

ブックマークレット

PC のブラウザなら、このボタンをブックマークバーにドラッグするだけです。

OALD に保存

スマホの場合は、下のコードをコピーしてください。

iPhone (Safari)

  1. 上のコードをコピーする
  2. Safari で適当なページを開き、共有ボタン →「ブックマークを追加」
  3. 名前を OALD に保存 にして保存
  4. ブックマーク一覧 → 編集 → いま作ったブックマークをタップ
  5. URL 欄の中身を消して、コピーしたコードを貼り付ける
  6. OALD の意味ページで、ブックマークから OALD に保存 を開く

iPhone（ショートカット・こちらが快適）

共有シートから 2 タップで済みます。

  1. ショートカットアプリ → 新規ショートカット
  2. 「Web ページで JavaScript を実行」を追加
  3. 中身を消して、下の 1 行を貼り付ける
  4. ショートカットの設定（ⓘ）→「共有シートに表示」をオン
  5. 受け取るデータを「Safari の Web ページ」に絞る
  6. OALD のページで 共有 → ショートカット名 をタップ

Android (Chrome)

  1. 上のコードをコピーする
  2. 適当なページで ☆ を押してブックマークを作る
  3. ブックマークを編集し、名前を oald、URL をコピーしたコードにする
  4. OALD のページを開き、アドレスバーに oald と入力して 候補に出たブックマークを選ぶ
    Android の Chrome はブックマークをタップしても実行できないため、 アドレスバーから呼び出します。

うまく動かないとき

実行すると、まず画面下にえんじ色の帯で 「OALD 単語帳: 読み込み中…」 が出ます。 この帯が出たかどうかで原因が分かれます。

見えたもの 原因と対処
何も出ない ブックマークレットが実行されていません。 貼り付けたときに先頭の javascript: が削られた可能性が高いです （多くのブラウザが安全のため自動で除去します）。 ブックマークを編集して、URL が javascript: で始まっているか 確認してください。
Android の Chrome では、ブックマーク一覧からタップしても実行されません。 アドレスバーに名前を入力して候補から選んでください。
帯が出たまま「読み込めませんでした」 通信の問題です。オフラインでないか確認してください。
帯は消えたがパネルが出ない 単語の意味ページではありません。検索結果や一覧のページでは動きません。 URL が /definition/english/… になっているか確認してください。
