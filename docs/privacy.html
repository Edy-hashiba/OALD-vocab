OALD 単語帳（OALD Vocab）／ 最終更新: 2026年9月14日

OALD 単語帳は、Oxford Advanced Learner's Dictionary で調べた単語を保存して 復習するための個人用ツールです。運営者が管理するサーバーは存在しません。

収集する情報

運営者は、利用者のいかなる情報も収集しません。 アクセス解析、広告、トラッキング用 Cookie のいずれも使用していません。

データの保存場所

データ保存先運営者から見えるか
保存した単語、語義、例文、メモ、復習履歴 利用者の端末内（ブラウザの IndexedDB / 拡張機能のストレージ） 見えない
同期を有効にした場合の単語データ 利用者自身の Google ドライブ内の oald-vocab.json 見えない
Google のアクセストークン ブラウザのメモリ内のみ（約1時間で失効。保存しない） 見えない

Google ドライブの利用について

同期機能を使う場合のみ、以下の権限を要求します。

https://www.googleapis.com/auth/drive.file

これは 本アプリが作成したファイルのみ にアクセスできる権限です。 利用者の Google ドライブにある他のファイルを閲覧・変更することはできません。

本アプリが作成・利用するファイルは oald-vocab.json 1 つだけです。 通信は利用者のブラウザと Google の間で直接行われ、運営者を経由しません。

Google から取得した情報は、利用者自身の端末間で単語データを同期する目的のみに 使用し、他のいかなる目的にも使用せず、第三者に提供しません。

第三者への提供

提供しません。運営者がデータを保持していないため、提供することができません。

外部との通信

  • GitHub Pages — アプリ本体（HTML・CSS・JavaScript）の配信のみ。 単語データが送られることはありません。
  • Google — 同期を有効にした場合のみ、サインインとドライブへの 読み書きのために通信します。
  • Oxford Learner's Dictionaries — 保存した単語の発音音声と 挿絵は、同社のサーバー上の URL を参照して再生・表示します。

ブックマークレットで単語を保存する際、単語データは URL のフラグメント （# 以降）で受け渡されます。フラグメントはブラウザがサーバーに 送信しない部分であるため、単語データが GitHub に送られることはありません。

データの削除

  • アプリ内で単語を個別に削除できます。
  • ブラウザのサイトデータを消去すると、端末内のデータは消えます。
  • Google ドライブの oald-vocab.json を削除すると、同期データは消えます。
  • Google アカウントの サードパーティ アプリとサービス から、本アプリのアクセス権をいつでも取り消せます。

Privacy Policy (English summary)

OALD Vocab is a personal vocabulary tool. There is no server operated by the developer. No information is collected, and there is no analytics, advertising or tracking.

Saved words are stored on the user's own device. If sync is enabled, they are also stored in a single file, oald-vocab.json, in the user's own Google Drive, using the drive.file scope — which grants access only to files this application itself created, and to nothing else in Drive. All traffic is directly between the user's browser and Google; it never passes through the developer.

Information obtained through Google APIs is used solely to synchronise the user's own vocabulary between their own devices. It is not used for any other purpose, is not shared with third parties, and is not used for advertising. The access token is kept in memory only and is never stored.

Users can delete their data at any time by removing words in the app, clearing browser site data, deleting the Drive file, or revoking access at myaccount.google.com/permissions.
