# OALD Vocab Saver

Oxford Advanced Learner's Dictionary で調べた単語を、意味・例文・コロケーション・
発音ごと保存して復習するための Chrome 拡張機能。

## 使い方

1. Chrome で `chrome://extensions` を開く
2. 右上の **デベロッパーモード** をオン
3. **パッケージ化されていない拡張機能を読み込む** → このフォルダの `extension/` を選択
4. ツールバーのアイコンから単語を入力 → OALD で検索
5. 定義ページ最上部のバーで **この単語を保存**

保存先は `chrome.storage.local`（ブラウザ内）。書き出し / 読み込みで JSON バックアップが取れる。

## 取得できる項目

| 項目 | 備考 |
|---|---|
| 見出し語 / 品詞 | |
| CEFR レベル | 見出し語全体と語義ごとの両方 |
| 発音記号 | 英 / 米 |
| 音声 | UK / US の MP3 直リンク |
| 語義 | 文法情報・ラベル・共起パターン付き |
| 例文 | 語義ごと |
| コロケーション | 見出し付き。**無料版は各カテゴリ3語まで**（完全版の Oxford Collocations Dictionary は要アクセスコード） |
| メモ | 自分で記入 |
| 保存日 | 一覧が保存日ごとにグルーピングされる |

## 復習

Leitner 方式。正解で次の箱へ（1 → 3 → 7 → 14 → 30 → 90 日）、不正解で箱 0 に戻る。

## 開発用プレビュー

拡張機能を読み込まずに復習画面だけ確認したいとき:

```
powershell -ExecutionPolicy Bypass -File tools\local-preview.ps1
```

`_local/shim.js` が `chrome.storage` を localStorage で代替する。

## 構成

```
extension/
  manifest.json
  src/
    parser.js     OALD の DOM から単語データを抽出（content script）
    content.js    定義ページ最上部の保存バー
    db.js         保存・SRS・書き出し / 読み込み（差し替え可能なストレージ層）
    popup.*       検索の入口
    review.*      保存リストと復習
```

## 予定 (Phase 2)

復習画面を GitHub Pages に切り出し、Google Drive の JSON を介して
PC とスマホで同期する。`db.js` を差し替えるだけで済むよう設計してある。

## クイズモード

復習タブの隣「クイズ」から、出題形式を選んで開始する。

| 形式 | 内容 | 対象 |
|---|---|---|
| 意味 → 単語（4択） | 英英の語義から単語を選ぶ | 4語以上 |
| 単語 → 意味（4択） | 単語から語義を選ぶ | 4語以上 |
| 意味 → 単語を入力 | つづりを打つ。頭文字と文字数がヒント | 全部 |
| 例文の穴埋め | 保存した例文から単語を隠す。活用形も認識 | 例文のある語 |
| 音声 → 単語を入力 | UK/US の発音を聞いて打つ | 音声のある語 |
| コロケーション（4択） | 結びつく語を選ぶ。誤答は他の単語の同種スロットから | コロケーションのある語 |
| イラスト → 単語（4択） | OALD の挿絵から選ぶ | 挿絵のある語のみ |
| 単語 → 意味を記述 | 英語で書いて模範解答と照合、自己採点 | 全部 |

- 入力形式は **マイクボタンで発音入力**もできる（Web Speech API。使えない環境ではボタンが出ないだけ）
- つづりが1〜2文字違いなら「つづり惜しい」として正解扱い
- 誤答の選択肢は同じ品詞・同じ CEFR レベルから優先的に選ばれる
- 結果はすべて Leitner の箱に反映される
- 解答表示のたびに UK / US の発音を聞ける

## 単語のライフサイクル

単語は3つの状態を持つ。

```
  学習中 ──[もう覚えた（卒業）]──▶ アーカイブ ──[90日経過]──▶ 削除
    ▲                                   │
    └────────[学習に戻す]────────────────┘
```

| 状態 | 復習・クイズに出る | 保存リスト | データ |
|---|---|---|---|
| 学習中 | ○ | 「学習中」 | あり |
| アーカイブ（卒業） | ✕ | 「アーカイブ」 | あり |
| 削除 | ✕ | 出ない | トゥームストーンのみ |

### 削除される条件

1. **手動削除** — カードの「削除」。即時・取り消し不可
2. **卒業から90日** — アーカイブしたまま90日復帰させなければ自動削除

「もう覚えた（卒業）」ボタンは復習カードとクイズの解答画面の両方にある。
採点用の「できた／できなかった」とは別のボタンで、1回の正解では卒業しない。

### 2か月経過・未卒業

保存から60日経っても卒業していない単語は、**削除せず**復習タブ上部の専用欄に
まとめて表示される。2か月覚えられていない単語こそ復習の価値が高いという判断。

### トゥームストーン（同期のための仕組み）

削除はレコードを消さず `{id, deleted: true, deletedAt}` を残す。マージは
`updatedAt` が新しい方を採用するので、削除も1つの更新として伝わる。これがないと
「スマホで削除 → PCに残っている → 同期で復活」が起きる。トゥームストーンは
90日後に実体ごと消える。

## 語義の選択保存

`run` のように語義が39個ある単語で全部を保存すると、目当ての意味が埋もれ、
復習カードもクイズも使いものにならなくなる。そこで **語義が2つ以上ある単語では、
各語義の右上にチェックボックスが出る**。読んでいる語義にチェックを入れれば
それだけが保存される。

- チェックは即保存。「適用」ボタンは無い
- 後日同じページを開いて別の語義にチェックを足せる（既存の語義は消えない）
- 保存順ではなく辞書の語義番号順に並ぶ
- 全部外すと単語ごと保存リストから消える
- 上部バーの「すべて保存 (39)」で従来どおり全語義を保存することもできる

保存済みの語義は復習カード上で `×` を押して個別に外せる（最後の1つは外せない）。

実測（`run`）:

| 保存内容 | サイズ |
|---|---|
| 全39語義 | 15,110 bytes |
| 1語義のみ | **744 bytes** |

語義には OALD の語義ID（`run_sng_7`）とグループ見出し（"manage" など）が
一緒に保存され、復習カードに見出しが表示される。旧バージョンで保存した語義は
IDを持たないが、定義文で照合して自動的にIDつきに統合される（重複しない）。

## クイズ問題の生成タイミング

問題は**保存していない**。「開始」を押すたびに `Quiz.build()` がその場で組み立て、
メモリ上の `session` に置くだけ。永続化されるのは選んだ出題形式（数十バイト）と
採点結果のSRS情報のみ。毎回違う組み合わせが出る。

## オフライン対応

拡張機能のコードは全てローカルにあり、外部スクリプト・CSS・Webフォント・`fetch` は
一切使っていない。単語データも `chrome.storage.local` にあるため、**8形式中6形式は
オフラインで完全に動く**。

| 形式 | オフライン |
|---|---|
| 意味 → 単語 / 単語 → 意味 / 意味 → 単語を入力 | ○ |
| 例文の穴埋め / コロケーション / 意味を記述 | ○ |
| 音声 → 単語を入力 | ✕ MP3 は OALD の URL を参照 |
| イラスト → 単語 | ✕ 画像は OALD の URL を参照 |

復習タブ（フラッシュカード）と SRS の採点もオフラインで動く。解答時の UK/US
発音ボタンだけ音が出ない。

オフライン時の挙動:

- 出題形式の選択画面に警告を出し、音声・イラストの2形式を選択不可にする
- クイズ中に回線が切れた場合、その問題は「オフラインのため再生できません」と表示し、
  **採点せずに**スキップできる
- 回線が戻れば自動的に2形式が復活する（`online` / `offline` イベントを監視）
- 画像の読み込みに失敗したときはサムネイルを1度試し、それも駄目なら
  「画像を読み込めませんでした」と表示する（壊れた画像アイコンを出さない）

音声・イラストをオフラインでも使えるようにするには、URL ではなくファイル本体を
端末にキャッシュする必要がある（Cache API）。これは Drive 同期と併せて実装予定。
